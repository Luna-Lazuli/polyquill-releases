# Polyquill downloads

Releases of Polyquill, a writing studio and story timeline in one app, made
by Luna Lazuli. The easiest way to get it is
[polyquill.app/download](https://polyquill.app/download), which always points
at the latest release here.

## Windows

**[Download the latest release](https://github.com/Luna-Lazuli/polyquill-releases/releases/latest)**
and take `Polyquill.exe` from its Assets, or download it directly:
[Polyquill.exe](https://github.com/Luna-Lazuli/polyquill-releases/releases/latest/download/Polyquill.exe).

Polyquill is one file with nothing to install. Put `Polyquill.exe` wherever you
like (your Programs or Desktop folder, for example) and run it. To update,
replace it with a newer download. Your projects are ordinary `.pqll` files
wherever you saved them, and the app's own settings and backups live in
`%LOCALAPPDATA%\Polyquill`, so replacing the exe never touches them.

- Requires Windows 10 or later, 64-bit.
- Try it free for 30 days of use. Buy a licence at
  [polyquill.app/pricing](https://polyquill.app/pricing) and enter the key in
  Help > Licence.
- The app is not code-signed yet, so Windows may show "Windows protected your
  PC". Choose More info, then Run anyway.
- Each release lists the SHA-256 of `Polyquill.exe`, and attaches it as
  `Polyquill.exe.sha256`, so you can check the download.
- To remove it, delete `Polyquill.exe`, and `%LOCALAPPDATA%\Polyquill` if you
  also want its settings and backups gone.

Questions or problems: [polyquill.app/contact](https://polyquill.app/contact).

This repository only hosts the release files; there is no source code here.
